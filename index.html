สเปก ติดตั้ง รันจากซอร์ส แก้ปัญหา

คู่มือภาษาไทย

ติดตั้ง VoiceStudio สำหรับสร้างเสียงและโคลนเสียงแบบ Local-first

VoiceStudio คือแอปโอเพนซอร์สสำหรับ voice cloning, voice design, dubbing, dictation, transcription และ audiobook โดยทำงานบนเครื่องเป็นหลัก ไม่ต้องมีบัญชีหรือ API key สำหรับ workflow หลัก

ดาวน์โหลดรุ่นล่าสุด เปิด GitHub
16 TTSเอนจินอ่านข้อความเป็นเสียง
11 ASRเอนจินถอดเสียงพูดเป็นข้อความ
646 ภาษาแคตตาล็อกภาษาขึ้นกับเอนจินที่เลือก

ก่อนติดตั้งต้องเตรียมอะไรบ้าง

ระบบปฏิบัติการที่รองรับ

macOS 13.3+ บน Apple Silicon, Windows 10/11 x64 และ Linux x86_64 ที่มี glibc 2.39 ขึ้นไป

ฮาร์ดแวร์แนะนำ

ขั้นต่ำ RAM 8 GB และพื้นที่ว่าง 10 GB; แนะนำ RAM 16 GB+, SSD 20 GB+ และ GPU NVIDIA CUDA หรือ Apple Silicon ถ้าต้องการความเร็ว

หมายเหตุ: CPU mode ใช้งานได้ แต่การสร้างเสียงอาจช้ากว่า GPU มาก และโมเดลเสริมบางตัวอาจต้องใช้ VRAM สูงกว่า 8 GB

วิธีติดตั้งแบบแนะนำ

ดาวน์โหลดแพ็กเกจให้ตรงกับเครื่อง

ไปที่หน้า Releases ล่าสุด แล้วเลือก DMG สำหรับ macOS Apple Silicon, MSI สำหรับ Windows x64 หรือ AppImage สำหรับ Linux x86_64

เปิดแอปและปล่อยให้ตั้งค่าอัตโนมัติ

การเปิดครั้งแรกจะสร้าง Python environment ที่จัดการโดยแอป และดาวน์โหลดโมเดลเริ่มต้นให้เอง หลังจากนั้นแอปจะใช้ environment และโมเดลเดิมซ้ำ

สร้างเสียงแรก

เปิด Voice Cloning, เพิ่มตัวอย่างเสียงที่สะอาด 5–15 วินาที, ใส่ข้อความ เลือกภาษา แล้วกด Generate

รันจากซอร์สสำหรับนักพัฒนา

ติดตั้ง development prerequisites ของโปรเจกต์ก่อน จากนั้นใช้คำสั่งต่อไปนี้เพื่อ clone และเปิด desktop app:

git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun install
bun run desktop

ถ้าต้องการเปิดเฉพาะ browser UI ให้ใช้ bun run dev แทน

ถ้าติดตั้งไม่สำเร็จ

ตรวจระบบอัตโนมัติ

ในแอปให้ไปที่ Settings → About → Run self-check หรือรันคำสั่ง diagnose แบบ deep จากโฟลเดอร์โปรเจกต์

uv run python backend/main.py --diagnose --deep

ข้อควรรู้เฉพาะแพลตฟอร์ม

  • macOS ต้องคลิกขวา → Open เพื่ออนุญาตครั้งแรก
  • Intel Mac ไม่รองรับ local Python backend ให้ใช้ remote backend แทน
  • Linux ต้องตรวจ glibc 2.39+ ก่อนใช้ AppImage
